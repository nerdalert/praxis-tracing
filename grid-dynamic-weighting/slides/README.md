# Weighted routing slide assets

The six-slide introductory deck and designed closing frame are in
[`weighted-routing-deck.md`](weighted-routing-deck.md). It is written as
Marp-compatible Markdown and uses neutral pool names throughout. The deck
does not claim that one particular ingress was exercised.

The production artwork is implemented in `deck.html` and uses the tracing
dashboard's neutral surfaces, red routing accents, status colors, and card
language. Render it with `scripts/render-intro-slides.sh`, then review the PNG
frames for readable spacing and labels before assembling the video.
