# Exit slide: spoken text and links

Grid lets the serving pool behind a model route be supplied by different
frameworks. This demo used Dynamo Frontend signals. Another deployment can
use llm-d and its EPP signals when the adapter and policy are configured for
those measurements. The routing interface stays consistent; the signal
semantics still matter. Explore Grid, Praxis AI, and Praxis core at the links
on screen. Thanks for watching.

On-screen links:

- Grid: https://github.com/praxis-proxy/grid
- Praxis AI: https://github.com/praxis-proxy/ai
- Praxis core: https://github.com/praxis-proxy/praxis
- Project organization: https://github.com/praxis-proxy

Do not imply a zero-downtime hot swap or that this one Dynamo recording
deployed llm-d. “Swappable” means a supported deployment choice with a
matching adapter, model route, and policy.
